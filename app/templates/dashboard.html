Current feature set

WG-Easy clients can be persistently assigned to routing groups targeting Default WAN or an outbound OpenVPN profile while private/local destinations continue using normal local routing. VPN-backed groups support block-on-failure or WAN fallback, and routing automatically follows tunnel connect/disconnect/reconnect events with retry recovery.
