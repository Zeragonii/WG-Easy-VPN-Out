Backup summary

What is backed up?

Included

VPN profiles, encrypted credentials, OpenVPN/WireGuard config files, routing groups, fallback settings, policy marks/tables and WG-Easy client assignments.

Excluded

Runtime logs, PID/auth files, retry state, probe tables, live tunnel state and other disposable runtime data.
